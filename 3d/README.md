# 3D files

Printable parts and their editable FreeCAD sources for the Sebastian enclosure/stand. See the main [README](../README.md) for assembly instructions.

## Print these

- `stand.stl` - the stand the unit sits in.
- `cover.stl` - the rear cover, attached to the carrier board/screen with 4 standoffs.
- `power-button.stl` - the power button (fits with its lip inside the case, long end facing out).
- `ports-cutout.stl` - the cutout piece for the carrier board's ports.

## Edit these

- `stand.FCStd` - FreeCAD source for the stand. Edit this and re-export if you want to change `stand.stl`.
- `cover.FCStd` - FreeCAD source for the cover. Edit this and re-export if you want to change `cover.stl`.
